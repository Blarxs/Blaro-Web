# Blaro Web

Blaro Web es el sitio web oficial de **Blaro**, creado para reunir sus proyectos, actualizaciones, recursos y evolución en un único espacio.

La web está diseñada con una estética moderna y minimalista, inspirada en interfaces actuales y con una identidad visual basada principalmente en blanco, negro y degradados de rojo, azul y morado.

## Versión

**version 1.0**

Primera versión completa de Blaro Web.

## Secciones

### Inicio

La página principal de Blaro Web, donde se muestran las novedades más recientes y una introducción al proyecto.

### About

Información sobre Blaro Web y Blaro, dividida en diferentes apartados para conocer mejor el proyecto.

### FTBIY

**Find The Best In Yourself**

Sección dedicada a las actualizaciones y proyectos de Blaro, incluyendo las diferentes General Updates.

### Evolution

Línea temporal que muestra la evolución de Blaro a través de sus diferentes etapas y proyectos.

### Tienda

Espacio destinado a los recursos y productos desarrollados por Blaro.

Actualmente incluye recursos como el **FTBIY Cursor Pack**.

## Tecnologías

El proyecto está desarrollado utilizando:

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

No se utilizan frameworks externos para la estructura principal de la web.

## Diseño

Blaro Web busca mantener una interfaz:

* Minimalista
* Moderna
* Clara
* Responsive
* Con animaciones sutiles
* Inspirada en interfaces de productos tecnológicos

Las animaciones están pensadas para aportar interacción sin sobrecargar la experiencia.

## Estado del proyecto

**Blaro Web v1.0 — En desarrollo**

La versión 1.0 establece la base principal del proyecto. Algunas funciones futuras todavía están previstas para próximas versiones.

Entre ellas:

* Sistema de usuarios e inicio de sesión local
* Sistema de carrito para la tienda
* Funciones sociales y de blog
* Nuevos recursos y productos
* Mejoras de interacción y animaciones
